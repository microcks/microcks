# Product

## Vision
Microcks is a Kubernetes-native tool for API Mocking and Testing. Our vision is to provide a unified platform for turning API and microservices assets (OpenAPI, AsyncAPI, gRPC, GraphQL, Postman collections) into live mocks in seconds, accelerating parallel development and testing.

## Key Features
- **Instant Mocking:** Deploy live mocks from existing API specifications without writing code.
- **Contract Testing:** Run conformance and non-regression tests against your API implementations.
- **Broad Protocol Support:** REST, GraphQL, gRPC, and event-driven architectures (AsyncAPI/Kafka).
- **CI/CD Integration:** Integrations with Jenkins, GitHub Actions, Tekton, and more via our CLI.

## Roadmap
Microcks is continuously evolving to support more protocols, deeper CI/CD integration, and enhanced Developer Experience. Current focus areas include expanding AsyncAPI protocol support, introducing DataContracts validation, and native IDE integrations.
